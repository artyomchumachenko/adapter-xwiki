@startuml
title /api/xwiki/search — логика семантического поиска

start
:Клиент вызывает эндпоинт /api/xwiki/search
с параметрами query и limit (по умолчанию 5);

:Нормализовать поисковый запрос;
:Сформировать векторные представления запроса
для каждой модели эмбеддингов (AI);

if (Вектора запроса не получены?) then (да)
  :Вернуть пустой список результатов;
  stop
endif

:Определить размер пула кандидатов
(больше, чем limit);
:Для каждой модели:
- найти наиболее похожие фрагменты страниц
в векторном хранилище (по расстоянию);
- оставить по одной «лучшей» части на страницу;

:Объединить результаты разных моделей
(ранжирование по RRF);
:Сортировать по суммарному рейтингу
и при равенстве по близости;
:Оставить top N результатов (limit);

:Для каждого результата
получить метаданные страницы из БД
(заголовок, ссылка, версия);

if (Метаданные страницы не найдены?) then (да)
  :Вернуть ошибку (страница отсутствует);
  stop
endif

:Сформировать список DTO:
заголовок + ссылка + сниппет + id + версия;
:Вернуть 200 OK и список результатов;
stop
@enduml
