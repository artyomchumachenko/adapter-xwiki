@startuml
title /api/xwiki/processAll — логика полного сбора и индексации

start
:Клиент вызывает эндпоинт /api/xwiki/processAll;

if (Получен список пространств в XWiki?) then (да)
  :Перебрать все пространства;
  if (Пространство не системное?) then (да)
    :Обойти все страницы в пространстве;

    if (У пространства есть список страниц?) then (да)
      :Для каждой страницы выполнить обработку;

      if (Страница не требует обработки?) then (да)
        :Пропустить страницу;
      else (нет)
        :Создать или обновить метаданные страницы в базе;
        :Загрузить содержимое страницы;
        :Нормализовать контент и разбить на части;

        if (Части отсутствуют?) then (да)
          :Завершить обработку страницы;
        else (нет)
          if (Страница уже существовала?) then (да)
            :Удалить старые вектора и части;
          endif

          :Для каждой части сохранить текст;
          :Для каждой модели эмбеддингов;
          :Получить эмбеддинг из AI;
          :Нормализовать вектор;
          :Сохранить вектор в базе;
        endif
      endif
    endif

    :Рекурсивно обработать дочерние пространства;
  endif
else (нет)
  :Обработка не выполняется;
endif

:Вернуть ответ 200 OK;
stop
@enduml
