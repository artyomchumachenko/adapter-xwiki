# Реестр нумерации материалов ВКР

Этот файл нужен, чтобы разные чаты и агенты продолжали единую нумерацию рисунков, таблиц, листингов, приложений и источников.

Перед генерацией текста ВКР агент обязан:

1. Открыть этот файл.
2. Найти последний номер нужного типа объекта.
3. Использовать следующий номер.
4. После генерации текста обновить соответствующий реестр.

Статусы:

- `план` - объект рекомендован, но еще не вставлен в текст;
- `черновик` - объект вставлен в черновик, но требует проверки;
- `готово` - объект проверен и может идти в финальную редакцию;
- `требует проверки` - нужно сверить данные, подпись, источник или номер.
