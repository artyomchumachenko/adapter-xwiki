# Рабочие тексты ВКР

Эта папка предназначена для поэтапного написания текста ВКР.

Правила:

1. Не писать основной текст главы, пока не заполнен `00-plan.md`.
2. Перед новой итерацией по главе читать все `.md` файлы этой главы.
3. Не повторять уже раскрытые мысли; новый файл должен продолжать предыдущие.
4. После каждой итерации обновлять `docs/vkr-control/progress.md`.
5. При добавлении рисунков, таблиц, листингов, приложений или источников обновлять `docs/reports/correlation.md`.

Папки:

- `1` - глава 1;
- `2` - глава 2;
- `3` - глава 3;
- `4` - глава 4.
