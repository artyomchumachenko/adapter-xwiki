`ГЛАВА 3 ПРОЕКТИРОВАНИЕ И РЕАЛИЗАЦИЯ СИСТЕМЫ`

Описать архитектуру, проектные решения и реализацию сервиса семантического поиска по XWiki.

## Логика главы

Глава должна показать самостоятельную инженерную реализацию: от архитектуры и интеграции с XWiki до хранения embeddings, REST API поиска и окружения запуска.

## Критерии закрытия главы

- Описаны все ключевые компоненты Java, Python и Docker контуров.
- Листинги кода не дублируют полный код, а показывают ключевые решения.
- Есть переход к экспериментальной оценке в главе 4.
- Объем не превышает `36 000` знаков с пробелами с допустимым отклонением.
