# Прогресс написания ВКР

Этот файл обновляется после каждой итерации написания текста. Статусы:

- `не начато`;
- `планируется`;
- `в работе`;
- `черновик`;
- `на проверке`;
- `закрыт`.

Раздел можно пометить `закрыт` только по критериям из `writing-workflow.md`.
