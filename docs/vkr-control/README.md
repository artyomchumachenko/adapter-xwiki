# Контур управления написанием ВКР

Эта папка содержит рабочие правила для поэтапного написания текста выпускной квалификационной работы.

Обязательный порядок для агента:

1. Прочитать `docs/tech/*.md`.
2. Прочитать `docs/reports/*.md`, особенно `correlation.md`.
3. Прочитать файлы из этой папки:
   - `writing-workflow.md`;
   - `volume-budget.md`;
   - `progress.md`.
4. Перед написанием главы открыть `docs/vkr/<номер главы>/00-plan.md`.
5. Если план главы еще не заполнен, сначала заполнить план, а не писать основной текст.
6. Перед каждой новой итерацией по главе прочитать все уже созданные `.md` файлы этой главы.
7. После итерации обновить `docs/vkr-control/progress.md`.

Рабочие тексты глав хранятся в `docs/vkr`:

- `docs/vkr/1` - глава 1;
- `docs/vkr/2` - глава 2;
- `docs/vkr/3` - глава 3;
- `docs/vkr/4` - глава 4.

Главное правило: файлы одной главы должны не повторять друг друга, а последовательно собираться в единый связный текст.
